Теория для задания №2 ЕГЭ

Векторы: координаты, длина, линейные операции, скалярное произведение, параллельность и перпендикулярность

1Вектор и его координаты

Вектор, заданный координатами:

a = (x₁; y₁),    b = (x₂; y₂)

Координаты вектора — это его смещение по оси x и по оси y.

Если даны точки A(xA; yA) и B(xB; yB), то вектор AB имеет координаты:

AB = (xB − xA;  yB − yA)
Правило: из координат конца вычитаем координаты начала.

На рисунке (задания 27–31) координаты вектора считаются по клеткам: сколько клеток вправо/влево (это x) и сколько вверх/вниз (это y). Влево и вниз — координаты отрицательные.

2Линейные операции с векторами

Для a = (x₁; y₁) и b = (x₂; y₂):

Сложение:

a + b = (x₁ + x₂;  y₁ + y₂)

Вычитание:

a − b = (x₁ − x₂;  y₁ − y₂)

Умножение на число k:

k · a = (k·x₁;  k·y₁)
Пример: найти a − 4b, если a = (x₁; y₁) и b = (x₂; y₂).
Сначала умножаем b на 4, затем вычитаем: a − 4b = (x₁ − 4x₂;  y₁ − 4y₂).

3Длина вектора

Длина вектора a = (x; y):

|a| = √(x² + y²)

Квадрат длины:

|a|² = x² + y²

Длина — это неотрицательное число.

Как искать длину c = α·a + β·b:
1находим координаты вектора c;
2считаем √(cx² + cy²).

4Скалярное произведение

Скалярное произведение a = (x₁; y₁) и b = (x₂; y₂):

a · b = x₁x₂ + y₁y₂

Результат — число, а не вектор.

Геометрический смысл:

a · b = |a| · |b| · cos φ

где φ — угол между векторами. Отсюда:

cos φ = (a · b) / (|a| · |b|)

Свойства:

  • a · a = |a|²
  • a · b = b · a

Знак скалярного произведения:

УсловиеУгол между векторами
a · b > 0острый
a · b = 0прямой (перпендикулярны)
a · b < 0тупой

5Перпендикулярность и параллельность

Для ненулевых векторов a = (x₁; y₁) и b = (x₂; y₂):

Перпендикулярность

Векторы перпендикулярны ⟺ их скалярное произведение равно нулю:

a ⊥ b  ⟺  a · b = 0  ⟺  x₁x₂ + y₁y₂ = 0

Параллельность (коллинеарность)

Векторы параллельны ⟺ их координаты пропорциональны:

a ∥ b  ⟺  x₁ / x₂ = y₁ / y₂

с учётом нулевых координат. Универсально — через определитель:

a ∥ b  ⟺  x₁y₂ − x₂y₁ = 0
Если b = k · a:
  • при k > 0 — векторы сонаправлены;
  • при k < 0 — векторы противоположно направлены.
Параллельные векторы могут быть направлены как в одну сторону, так и в противоположные.

6Как решать задания №2

Задания 1–11 Найти длину линейной комбинации

1находим координаты линейной комбинации (сложить/вычесть/умножить);
2считаем длину по формуле √(x² + y²).

Задания 12–13 Найти скалярное произведение

a · b = x₁·x₂ + y₁·y₂

Задания 27–31 По рисунку

1по клеткам находим координаты a и b (от начала к концу вектора);
2подставляем в формулу a · b = x₁x₂ + y₁y₂.

Коротко — всё главное

|a| = √(x² + y²)
a · b = x₁x₂ + y₁y₂
a ⊥ b  ⟺  a · b = 0
a ∥ b  ⟺  x₁y₂ − x₂y₁ = 0
